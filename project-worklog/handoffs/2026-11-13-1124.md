## Đang chờ và bước tiếp theo

- Xác định mục tiêu chỉ xem hay tạo/sửa dashboard, region và tình trạng triển khai/dashboard hiện tại; kiểm tra lỗi quyền nếu có. Nếu cần kiểm tra CLI, bạn tự chạy STS và liệt kê dashboard; không gửi ID tài khoản, ARN đầy đủ, access key, mật khẩu hay nội dung nhạy cảm.
- Dựa trên lỗi/kết quả thực tế, hướng dẫn theo từng giai đoạn; không mặc định cấp thêm quyền hay triển khai tài nguyên. Nếu dashboard chưa tồn tại, trao đổi cách tạo và quyền cần thiết trước khi hướng dẫn thay đổi.
- Chưa chạy kiểm thử, chưa gọi AWS, chưa sửa code hoặc tài nguyên; mới có xác nhận đăng nhập Console, chưa xác nhận truy cập CloudWatch. Không ghi secret trong file này.

## Nguồn đã đối chiếu

- [IAM users and credentials](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_users.html): phân biệt console password và access key.
- [Quản lý access key](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_credentials_access-keys.html): bảo vệ key, ưu tiên credential tạm thời.
- [CloudWatchReadOnlyAccess](https://docs.aws.amazon.com/aws-managed-policy/latest/reference/CloudWatchReadOnlyAccess.html): phạm vi policy chỉ đọc AWS quản lý.
- [CloudWatch permissions reference](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/permissions-reference-cw.html): quyền cần thiết để liệt kê dashboard và xem metric.
- [Quản lý mật khẩu IAM user](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_credentials_passwords_admin-change-user.html): tạo hoặc đặt lại mật khẩu Console cho user hiện có; [đăng nhập IAM](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_users_sign-in.html): account ID/alias, user name và mật khẩu.
